# 🚗 EBAC Motors

Landing page desenvolvida durante minha jornada de aprendizado em **Desenvolvimento Front-end**, simulando o site de uma concessionária de veículos.

O projeto utiliza **HTML, CSS e JavaScript/jQuery**, com foco na criação de uma interface responsiva, organizada e interativa.

## 📸 Preview

![EBAC Motors](./src/pages/assets/preview.png)

---

## ✨ Funcionalidades

* 🎞️ Carrossel de veículos;
* 🍔 Menu responsivo;
* 🚘 Seção de veículos em destaque;
* 🏷️ Seção de promoções;
* 📋 Formulário de contato;
* 📱 Máscara para telefone;
* 🎯 Seleção automática do veículo de interesse;
* 🔗 Navegação entre as seções;
* 📌 Cabeçalho com posicionamento `sticky`.

## 💡 Conceitos aplicados

* Estruturação semântica com **HTML5**;
* Estilização e layout com **CSS3**;
* **Flexbox**;
* Responsividade com media queries;
* Manipulação do DOM;
* Eventos com **jQuery**;
* Máscara de campos;
* Carrossel de imagens;
* Navegação e rolagem entre seções;
* Posicionamento `sticky`;
* Organização de arquivos e recursos.

---

## 📱 Responsividade e interações

A interface foi desenvolvida considerando diferentes tamanhos de tela.

Entre as interações implementadas estão:

* Menu hambúrguer para dispositivos menores;
* Carrossel de veículos;
* Rolagem entre seções;
* Preenchimento automático do veículo selecionado;
* Máscara no campo de telefone;
* Efeitos visuais durante a navegação.

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/Luizprofissional2025/Ebac_motors.git
```

Entre na pasta:

```bash
cd Ebac_motors
```

Como o projeto utiliza **HTML, CSS e JavaScript**, não é necessário instalar dependências.

Abra o arquivo:

```text
index.html
```

Também é possível utilizar o **Live Server** no VS Code para executar o projeto localmente.
